Geobrawl

A 2D platform fighter in Unity

Technologies Used

C# Unity
Visual Studio

Overview

Geobrawl is a 2D platform fighter game developed using the Unity engine. The project aimed to create a unique experience by mixing rougelike upgrade mechanics with weapon-based platform fighter gameplay.

Game Menu

Challenges

This project was created with a small team over the course of about 4 months, so communication and organization were important. My initial role in the project was primarily focused on programming the core gameplay mechanics, including character movement, combat systems, and the upgrade system, but I also took on a leadership role in coordinating development efforts.

Solutions

We addressed the challenge by implementing a structured development process that emphasized clear communication and regular team meetings. We focused on using SCRUM principles to manage the project workflow and managed to successfully complete the project slightly ahead of schedule.

Results & Takeaways

This project was a great learning experience for me since I got to learn a lot about working with a team on a fast-paced project. I gained valuable insights on project management and team communication that I have applied in ym work since this project. Our team was happy with the results of the game, and while we didn't publish it, we received positive feedback at local demos and presentations.
